# Criteria catalog

Pick what applies. Define each in one line so scorers agree on meaning.

| Criterion | Question it answers |
|---|---|
| Fit to requirements | Does it meet the functional and non-functional needs without workarounds? |
| Security and compliance | Does it satisfy required controls (SOC 2, HIPAA, data residency)? |
| Total cost (3 yr) | License, infra, support, and people cost over three years |
| Operational burden | Who patches, scales, and gets paged? |
| Reliability | Documented SLA, failure modes, blast radius |
| Team skill fit | Can the current team run it in 90 days? |
| Lock-in / exit cost | What does leaving cost, in effort and data portability? |
| Integration effort | Work to connect to identity, logging, existing systems |
| Time to value | Weeks until first production use |
| Vendor viability | Funding, roadmap, support quality, references |
| Scalability | Headroom at 10x load without redesign |
| Strategic alignment | Does it move toward or away from the target architecture? |
